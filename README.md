# Vantara-Customer-Intelligence-Platform
An internal analytics system that ingests historical transaction data and produces churn risk scores, customer lifetime value estimates, next-purchase probability, product recommendations, and customer segments.

# Project Setup
1. **Manual**
    - create virtual environment and install dependencies
    ```
    uv sync
    ```
    - activate virtual environment 
        * linux 
        ```
        source .venv/bin/activate
        ```
        * windows
        ```
        .venv\scripts\activate
        ```
